# Chemical Plant KPI Dashboard

## Project Status

🟡 In Progress

## Objective

To develop a simple chemical plant performance analysis using production data and Excel, with the eventual goal of creating an interactive Power BI dashboard.

## Key Performance Indicators

- Production
- Feed consumption
- Product yield
- Energy consumption
- Specific energy consumption
- Downtime

## Tools

- Microsoft Excel
- Power BI (planned)
- GitHub

## What I am Learning

This project is part of my learning journey in data analysis using chemical engineering examples.

I am starting with Excel and gradually moving toward Power BI and more advanced data analysis.

## Project Roadmap

- [ ] Create production dataset
- [ ] Structure data in Excel
- [ ] Calculate production KPIs
- [ ] Create PivotTables
- [ ] Analyse the results
- [ ] Build Power BI dashboard
- [ ] Document findings
- [ ] Publish final project
